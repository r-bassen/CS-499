## WNC-NFA Chapter Website

A full-stack website application as a final capstone project for the SNHU BS in Computer Science degree. The project demonstrates technical proficiency in frontend development, backend API design and database management.

**Live Site:** [r-bassen.github.io/CS-499](https://r-bassen.github.io/CS-499/)

------
## Features
- Faculty survey accessible with a demo login
- Survey results with aggregated response data
- Chapter updates page with categorized news articles
- Contract document viewer
- Responsive navigation with React Router

## Artifacts
This project was built using two CS-465 Full Stack artifacts as a foundation:

1. **Software Design & Engineering** — Migrated Angular frontend to React with Vite
2. **Algorithms and Data Structures** - Implemented quicksort algorithm to sort and aggregate survey responses
3. **Databases** — Migrated MongoDB to PostgreSQL to store survey responses
